# Device support

No device profiles or discovery providers are enabled in the foundation. Connected devices screen is a planned state, not a simulated inventory. No USB, serial or network interfaces are opened or queried.

Later validation candidates from the guidelines: GL.iNet GL-MT3000, Huawei E8372, TP-Link Archer AX23. These are candidates only; model names alone never grant backup or builder capabilities. Record exact hardware revision, firmware and evidence before assigning support.

Capabilities must independently report SUPPORTED, UNSUPPORTED, UNKNOWN, REQUIRES_AUTH, REQUIRES_TOOL or EXPERIMENTAL. UNKNOWN never means supported.
